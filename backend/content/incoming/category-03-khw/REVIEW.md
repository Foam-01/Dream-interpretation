## วิธีแยกข้อมูล

- แยกด้วยคำว่า "เลขเสี่ยงโชค"; ชื่อ = คำแรกก่อนช่องว่าง
- **ตรวจย้อนกลับ:** ชื่อ + คำทำนาย + เลข ของทั้ง 24 รายการ ต่อกันแล้วตรงกับต้นฉบับทุกตัวอักษร (ไม่นับช่องว่าง)
- คู่รัก: ต้นฉบับขึ้นย่อหน้าใหม่กลางคำ "ความ|ซื่อสัตย์" — ต่อกันโดยไม่เว้นวรรค ("ความซื่อสัตย์")
- เลขเก็บเป็น string ตามต้นฉบับ (คลอดบุตร: `"01"`, `"02"` เลข 0 นำหน้าไม่หาย)
- `short` = คำทำนายเต็มตามต้นฉบับ
