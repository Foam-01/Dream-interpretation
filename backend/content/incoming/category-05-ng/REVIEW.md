# หมวด ง — รายงานตรวจทานก่อนนำเข้า

- ต้นฉบับ: `dreams-source.md` (ข้อความที่เจ้าของแอปส่งมา ไม่ได้แก้ไข) — 12 รายการ
- ไฟล์นำเข้า: `dreams.json` (`dreamapp-dreams/v1`, ทุกรายการ `DRAFT` ในไฟล์, หมวด `letter-ng` = "หมวด ง")
- กติกาเดียวกับหมวด ก–ฆ: ไม่ระบุแหล่งที่มา, "ไม่ควรเสี่ยง" เก็บเป็น `"noLuckyNumbers": true`,
  แก้คำผิดและชื่อซ้ำให้เข้ากับเนื้อหา (บันทึกใน `corrections.json`)
- สถานะ: นำเข้าและเผยแพร่แล้วใน **ฐานข้อมูลในเครื่อง** (12 รายการ `VERIFIED`) และฝังในแอปแล้ว — **ยังไม่ขึ้น Neon**

## เลขของ "งู" มีแค่ 33

ต้นฉบับให้เลขเสี่ยงโชคของ "งู" แค่ `33` (ไม่มีเลข 3 ตัว) เจ้าของแอปยืนยันให้ใช้ตามนั้น จึงแก้ระบบให้รองรับเลข 2 ตัวอย่างเดียว:
- migration `0004_two_digit_only_numbers`: เลข 3 ตัวว่างได้ ถ้ามีเลข 2 ตัว (ยังบังคับเลข 2 ตัวเมื่อไม่ใช่ "ไม่ควรเสี่ยง")
- ตัวนำเข้า: `threeDigit` ต้องมี แต่เป็น `[]` ได้
- แอป: หน้าคำทำนายแสดงแค่ช่อง "สองตัว" เมื่อไม่มีเลข 3 ตัว
