- ต้นฉบับ: `dreams-source.md` (ข้อความที่เจ้าของแอปส่งมา ไม่ได้แก้ไข) — 9 รายการ
- ไฟล์นำเข้า: `dreams.json` (`dreamapp-dreams/v1`, ทุกรายการ `DRAFT` ในไฟล์, หมวด `letter-fan` = "หมวด ฟ")
- กติกาเดียวกับหมวดก่อนหน้า: ไม่ระบุแหล่งที่มา, "ไม่ควรเสี่ยง" และ "ยังไม่มีโชคในการเสี่ยง" เก็บเป็น `"noLuckyNumbers": true`,
  แก้คำผิดและชื่อซ้ำให้เข้ากับเนื้อหา (บันทึกใน `corrections.json`)
- สถานะ: นำเข้าและเผยแพร่แล้วใน **ฐานข้อมูลในเครื่อง** (9 รายการ `VERIFIED`) และฝังในแอปแล้ว — **ยังไม่ขึ้น Neon**

## หมายเหตุ

- **ไฟ** มี 5 รายการชื่อซ้ำกัน → ตั้งชื่อตามเนื้อหา: ไฟบนภูเขา / ไฟในเตา / ไฟไหม้บ้าน / ไฟโคมและเทียน / ไฟไหม้ป่า
- **ฟัน / ฟ้า / ฟ้าผ่า** ตั้งชื่อให้ชัด: ฟันคลอน / ฟ้าผ่าตัว / ฟ้าผ่าต้นไม้
- "แต่จะได้ทุกข์ลาภภายหลัง" → "แต่จะได้ลาภภายหลัง" (คำว่า ทุกข์ลาภ ไม่มีความหมาย น่าจะพิมพ์ผิด) — ถ้าต้นฉบับตั้งใจเป็นคำอื่นแจ้งได้ครับ
