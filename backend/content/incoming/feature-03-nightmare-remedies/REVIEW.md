# เมนู 3 — เคล็ดลับแก้ฝันร้าย

ต้นฉบับ: `source.md` (เก็บตามที่ได้รับ) → ข้อมูลในแอป: `lib/data/nightmare_remedies.dart`
ตรวจแล้วว่าข้อความตรงกับต้นฉบับทุกตัวอักษร ยกเว้นคำที่แก้ด้านล่างและช่องว่าง

- บทนำ 7 ย่อหน้า · เคล็ดแก้ฝัน 18 ข้อ (ฝันว่า / ทายว่า / วิธีแก้) · ย่อหน้าปิดท้าย
- ตัดทิ้ง: บรรทัดรหัส `90bedfe1-…` / `0bee45b3-…` และท้ายหน้า "พร้อม แปะกงชี้โชค 1,000 ตัวเลข 153" (ติดมาตอนคัดลอก)
- ต่อย่อหน้าที่ถูกตัดกลางประโยค: "…ให้พรว่า / “ฝันดีจะมีลาภ”…" และ "…จะถือว่า / เป็นเรื่องจริงจัง…"
- เอาข้อมูลตัวอย่างเดิมออก (4 ขั้นตอนและคาถา "ทุสสุปินัง…" ที่ไม่มีที่มา)

## คำที่แก้

| ต้นฉบับ | แก้เป็น |
|---|---|
| ศิษะ | ศีรษะ |
| เป็นทุกข์ตกกังวล | เป็นทุกข์วิตกกังวล |
| กลายเป้นดี | กลายเป็นดี |
| นับเนืองเข้าในข่าย | นับเนื่องเข้าในข่าย |
| หักกลบลบร้าง | หักกลบลบล้าง |
| ตำรับรำ่โบราณ | ตำรับตำราโบราณ |
| ที่เป็นคุ้มครองแล้ว | ที่เป็นที่พึ่งคุ้มครองแล้ว |
| แล้วันฝัน (2 ที่) | แล้วแก้ฝัน |
| ลำบาท | ลำบาก |
| ทายว่าว่า | ทายว่า |
| แก้ฝันได้ตุ่นเรือน | แก้ฝันใต้ถุนเรือน |
| มาดูนมเรา | มาดูดนมเรา |
| ตกส้วมอุจจาระ มีแต่ซื้ออย่างเดียว | ตกส้วม เปื้อนอุจจาระไปทั้งตัว |

## เรียงลำดับ

- "ขี่ควาย แล้วตกลงมา … ทางสามแพร่ง" ย้ายมาไว้ต่อจากข้อ "ขี่ม้า หรือ วัวควาย แล้วตก…" (ข้อ 4 → 5) เพราะเรื่องคล้ายกัน
  แต่วิธีแก้ต่างกัน จึงยังแยกเป็น 2 ข้อตามต้นฉบับ

เจ้าของเนื้อหาให้ตัดสินทั้ง 3 จุดเอง ("นายจัดการได้เลย เอาให้ เหมาะสม")
