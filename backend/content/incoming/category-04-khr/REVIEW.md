- สถานะ: นำเข้าและเผยแพร่แล้วใน **ฐานข้อมูลในเครื่อง** (4 รายการ `VERIFIED`) และฝังในแอปแล้ว — **ยังไม่ขึ้น Neon**

## วิธีแยกข้อมูล

- แยกด้วยคำว่า "เลขเสี่ยงโชค"; ชื่อ = คำแรกก่อนช่องว่าง
- **ตรวจย้อนกลับ:** ชื่อ + คำทำนาย + เลข ของทั้ง 4 รายการ ต่อกันแล้วตรงกับต้นฉบับทุกตัวอักษร (ไม่นับช่องว่าง)
- เลขเก็บเป็น string ตามต้นฉบับ (เลข 0 นำหน้าไม่หาย: `"08"`, `"09"`, `"04"`)
