# หมวด ร — รายงานตรวจทานก่อนนำเข้า

- ต้นฉบับ: `dreams-source.md` (ข้อความที่เจ้าของแอปส่งมา ไม่ได้แก้ไข) — 16 รายการ
- ไฟล์นำเข้า: `dreams.json` (`dreamapp-dreams/v1`, ทุกรายการ `DRAFT` ในไฟล์, หมวด `letter-r` = "หมวด ร")
- กติกาเดียวกับหมวดก่อนหน้า: ไม่ระบุแหล่งที่มา, "ไม่ควรเสี่ยง" และ "ยังไม่มีโชคในการเสี่ยง" เก็บเป็น `"noLuckyNumbers": true`,
  แก้คำผิดและชื่อซ้ำให้เข้ากับเนื้อหา (บันทึกใน `corrections.json`)
- สถานะ: นำเข้าและเผยแพร่แล้วใน **ฐานข้อมูลในเครื่อง** (16 รายการ `VERIFIED`) และฝังในแอปแล้ว — **ยังไม่ขึ้น Neon**

## หมายเหตุ

- **"ราชา-ราชินี ดูคำว่า กษัตริย์ ในหมวดอักษร ก."** เป็นการอ้างอิง ไม่ใช่คำทำนาย → ไม่สร้างเป็นรายการ (หมวด ก มีรายการ **กษัตริย์** `k-king` อยู่แล้ว)
- **เรือ** มี 3 รายการชื่อซ้ำกัน → เรือล่ม / เรือกลางพายุ / เรือหลุดลอย
- **ไร, มด** → **ไรและมด**
- **ร้องไห้** ต้นฉบับมีเลข 3 ตัว (56, 57, 256) — ใช้ตามต้นฉบับ
- **ราหู** เลขสามตัวขึ้นต้นด้วย 0 (050, 060) — ใช้ตามต้นฉบับ
