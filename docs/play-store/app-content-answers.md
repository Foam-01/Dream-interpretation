# คำตอบสำหรับหน้า App content ใน Play Console (ร่าง)

อ้างอิงจากพฤติกรรมของแอปเวอร์ชัน 1.0.0: ไม่มีบัญชีผู้ใช้ ไม่มีโฆษณา เนื้อหาอยู่ในแอป
ข้อมูลที่ออกจากเครื่องมีเฉพาะรายงานของ Firebase Crashlytics (ดู `docs/crash-reporting.md`)
ถ้าภายหลังเพิ่มโฆษณา (AdMob) หรือระบบสมาชิก ต้องกลับมาแก้ทุกหัวข้อในไฟล์นี้

## Data safety

| คำถาม | คำตอบ |
|---|---|
| แอปเก็บหรือแชร์ข้อมูลผู้ใช้ประเภทที่กำหนดหรือไม่ | Yes |
| ข้อมูลทั้งหมดเข้ารหัสระหว่างส่งหรือไม่ | Yes (Crashlytics ส่งผ่าน HTTPS) |
| ผู้ใช้ขอให้ลบข้อมูลได้หรือไม่ | No (ไม่มีบัญชี ระบุเจ้าของข้อมูลไม่ได้ ข้อมูลถูกลบเองใน 90 วัน) |

ประเภทข้อมูลที่ต้องประกาศ:

| ประเภท | Collected | Shared | ประมวลผลชั่วคราว | บังคับ/เลือกได้ | วัตถุประสงค์ |
|---|---|---|---|---|---|
| App info and performance → Crash logs | Yes | No | No | บังคับ (ผู้ใช้ปิดไม่ได้) | Analytics |
| App info and performance → Diagnostics | Yes | No | No | บังคับ | Analytics |
| Device or other IDs (installation ID ของ Crashlytics) | Yes | No | No | บังคับ | Analytics |

ประเภทอื่นทั้งหมด (Location, Personal info, Financial info, Messages, Photos, Contacts, App activity,
Web browsing ฯลฯ): ไม่เก็บ

หมายเหตุ: การส่งให้ Firebase ในฐานะผู้ให้บริการ (service provider) ไม่นับเป็น "Shared" ตามนิยามของ Play

## Content rating (แบบสอบถาม IARC)

| คำถาม | คำตอบ |
|---|---|
| หมวดของแอป | Reference, News, or Educational (หรือ Utility ถ้าไม่มีตัวเลือกนี้) |
| ความรุนแรง / เนื้อหาทางเพศ / ภาษาหยาบคาย / ยาเสพติด | No ทั้งหมด* |
| การพนันด้วยเงินจริง หรือการจำลองการพนัน | No (แอปไม่มีการเดิมพันหรือเกมเสี่ยงโชค) ถ้าแบบสอบถามมีคำถามแยกเรื่อง "เนื้อหาอ้างอิงถึงการพนัน/สลาก" ให้ตอบ Yes เพราะมีเมนูเลขตามวันออกสลาก |
| ผู้ใช้สื่อสารหรือแชร์เนื้อหากันได้ | No |
| แชร์ตำแหน่งที่ตั้ง | No |
| ซื้อสินค้าดิจิทัลในแอป | No |

\* เจ้าของต้องยืนยัน: ถ้ามีคำทำนายที่บรรยายความรุนแรง ความตาย หรือเรื่องเพศแบบชัดแจ้ง ให้ตอบตามจริง

## Target audience and content

- กลุ่มอายุ: เลือกเฉพาะ **18 ปีขึ้นไป**
  เหตุผล: แอปมีเลขนำโชคที่คนไทยเชื่อมโยงกับสลาก การไม่รวมผู้เยาว์ลดความเสี่ยงด้านนโยบาย
  และทำให้ไม่ต้องเข้าเงื่อนไขนโยบาย Families
- แอปดึงดูดเด็กโดยไม่ตั้งใจหรือไม่: No

## หัวข้ออื่น

| หัวข้อ | คำตอบ |
|---|---|
| Government apps | No |
| Financial features | ไม่มีฟีเจอร์การเงิน |
| Health | ไม่มีฟีเจอร์สุขภาพ |
| News app | No |
| Advertising ID | No (ตรวจ manifest ของ release build แล้วเมื่อ 12 พ.ย. 2026: ไม่มีสิทธิ์ `AD_ID`) |

## คำถามตอนขอขึ้น Production (หลัง closed test 14 วัน)

เก็บข้อมูลเหล่านี้ไว้ระหว่างทดสอบ เพราะ Google จะถาม:

1. หาผู้ทดสอบยากง่ายแค่ไหน
2. ผู้ทดสอบใช้ครบทุกฟีเจอร์หรือไม่
3. การใช้งานของผู้ทดสอบเหมือนผู้ใช้จริงหรือไม่
4. สรุป feedback และวิธีเก็บ (เช่น ถามใน LINE กลุ่ม หรือ Google Form)
5. กลุ่มเป้าหมาย คุณค่าของแอป และยอดติดตั้งที่คาดในปีแรก
6. แก้ไขอะไรจากผลทดสอบ และตัดสินอย่างไรว่าพร้อมขึ้น Production
