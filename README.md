## Data source

By default the app uses bundled SAMPLE data. Build with
`--dart-define=API_BASE_URL=http://10.0.2.2:3000/api/v1` to read dreams from the backend in `backend/`.
See [docs/api-mode.md](docs/api-mode.md).
